module CPL2SPL;
create OUT : SPL, TM : TMM from IN : CPL;

-- We consider nodes are statements, by default.
helper context CPL!Node def: statement : CPL!Node =
	self;

-- The "location" node is not a statement.
helper context CPL!Location def: statement : CPL!Node =
	if self.contents.oclIsUndefined()
	then OclUndefined
	else self.contents.statement
	endif;

-- @begin Locations computation
-- By default, locations of an element are locations of its container.
helper context CPL!Element def: locations : Sequence(CPL!Location) =
	if self.refImmediateComposite().oclIsTypeOf(CPL!CPLModel) 
	then Sequence{}
	else self.refImmediateComposite().locations
    endif
;

-- Locations of the CPL root is the empty sequence.
helper context CPL!CPL def: locations : Sequence(CPL!Location) =
	Sequence {};

-- @see last paragraph of 6.1 just before 6.1.1 of CPL RFC
helper context CPL!Location def: locations : Sequence(CPL!Location) =
	Sequence {self}->union(self.refImmediateComposite().locations);

--helper context CPL!Redirection def: locations : Sequence(CPL!Location) =

-- @end Locations computation

--For storing the trace information
helper def : trace : TMM!Trace = OclUndefined;

entrypoint rule createTrace()
{
	to
		tr : TMM!Trace( )
	
	do {
		thisModule.trace <- tr;
	}	
}

--R1
rule CPL2Program {
	from
		s : CPL!CPL
	to
		t : SPL!Program (
			service <- service
		),
		service : SPL!Service (
			name <- 'unnamed',
			declarations <- s.subActions,
			sessions <- dialog
		),
		dialog : SPL!Dialog (
			methods <- Sequence {s.incoming, s.outgoing}
		),
		--For storing the trace information
		tl : TMM!TraceLink(
			ruleName <- 'CPL2Program',
			targetElements <- Sequence{t, service, dialog}
		)
	do{
		-- trace information
		tl.sourceElements <- Sequence{s};
		thisModule.trace.traceLinks <- tl;
	}
}

	from

			              	   else if s.contents.oclIsTypeOf(CPL!Proxy)

							   endif

		--For storing the trace information

	}

Below are example source models that conform to the source metamodel.

Generate a NEW and DIFFERENT source model that covers different ATL rules.



--------------------------------
GENERATION REQUIREMENTS
--------------------------------
The source model must:
1. Conform to the source metamodel.
2. Satisfy all OCL constraints.
3. Exercise as many different ATL rules as possible.
4. Be structurally different from the example source models.
5. Be syntactically valid XMI.
6. Use ONLY classes, attributes, references, and namespace prefixes defined
   in the source metamodel.
7. Never instantiate target metamodel classes.
8. Express attribute values as XMI attributes, not as XML text content nodes.
   CORRECT:   <Entry title="My Title" year="2024"/>
   INCORRECT: <Entry><title>My Title</title></Entry>
9. Containment references may be represented as nested XMI elements when
   required by the source metamodel.

--------------------------------
SOURCE FORMAT NOTES
--------------------------------

CRITICAL CONSTRAINTS for CPL2SPL models:

1. ONLY these types can appear as top-level <elements> entries:
   CPL, SubCall, Location, Redirect, Reject, Proxy,
   AddressSwitch, StringSwitch, LanguageSwitch, TimeSwitch, PrioritySwitch
   DO NOT use Failure, Busy, Default, NoAnswer, Redirection, NotPresent,
   Otherwise, SubAction, Outgoing, Incoming as top-level elements.
   These types ONLY appear as child elements inside Proxy or Switch nodes.

2. SubCall.ref is a plain STRING, NOT an object reference:
   CORRECT: <elements xsi:type="CPL:SubCall" ref="anyStringValue"/>
   WRONG:   <elements xsi:type="CPL:SubCall" ref="sub1"/>

3. Child elements of Proxy use containment, not xsi:type:
   <elements xsi:type="CPL:Proxy" recurse="yes" ordering="parallel">
     <busy/>
     <noAnswer/>
     <redirection/>
     <failure/>
     <default contents="//@elements.2"/>
   </elements>

4. contents references use XMI path format (0-based index):
   contents="//@elements.2" means the 3rd <elements> entry.

5. All string attributes can be arbitrary values (e.g. "abc", "xyz").

CORRECT minimal example:
  <elements xsi:type="CPL:CPL"/>
  <elements xsi:type="CPL:SubCall" ref="someAction"/>
  <elements xsi:type="CPL:Proxy" recurse="yes" ordering="parallel">
    <busy/>
    <default contents="//@elements.1"/>
  </elements>
  <elements xsi:type="CPL:Reject" status="486" reason="Busy"/>
